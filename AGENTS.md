# Agent guide

This repository is an email campaign assessment: Angular, a Laravel API, MySQL, and a Laravel queue. Read the constraints before changing behaviour.

- [docs/guardrails.md](docs/guardrails.md) — phase gate (**passed**), API contract, statuses, and out-of-scope technology.
- [docs/engineering-rules.md](docs/engineering-rules.md) — verify the affected flow, then commit with Conventional Commits.
- [docs/adr/README.md](docs/adr/README.md) — accepted decisions (0001–0010). Do not edit an accepted decision in place.
- [docs/patterns.md](docs/patterns.md) — patterns that are in use and patterns that are waiting.

Phase 1 (ADR-0001–0007) and Phase 2 close-out (Scramble, Postman, CI, ADR-0010 deferral) are in place. Do not build the block editor or Storybook unless a **new** ADR supersedes ADR-0010.
