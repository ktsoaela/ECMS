# Agent guide

This repository is an email campaign assessment: Angular, a Laravel API, MySQL, and a Laravel queue. Read the constraints before changing behaviour.

- [docs/guardrails.md](docs/guardrails.md) — phase gate, API contract, statuses, and out-of-scope technology.
- [docs/engineering-rules.md](docs/engineering-rules.md) — verify the affected flow, then commit with Conventional Commits.
- [docs/adr/README.md](docs/adr/README.md) — accepted and proposed decisions. Do not edit an accepted decision in place.
- [docs/patterns.md](docs/patterns.md) — patterns that are in use and patterns that are waiting.

Do not start Phase 2 until [docs/guardrails.md](docs/guardrails.md) says the gate has passed. Proposed records, including Scramble, CI, and the block editor, stay unimplemented until then.

`poa.md` is local research notes. It is gitignored and is not the submission README.
